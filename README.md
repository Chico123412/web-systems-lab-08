# Study Planner — лабораторна робота №8

Навчальний застосунок для керування списком завдань, створений на React та TypeScript.

## Реалізовано

- додавання навчальних завдань;
- проста перевірка обов'язкової назви;
- позначення завдання виконаним або невиконаним;
- видалення завдань;
- фільтрація всіх, виконаних і невиконаних завдань;
- автоматичний підрахунок статистики;
- умовне відображення повідомлення для порожнього списку;
- поділ застосунку на окремі React-компоненти.

## Технології

- React 19;
- TypeScript;
- Vite;
- ESLint;
- CSS із використанням BEM-подібних назв класів.

## Запуск

```bash
npm install
npm run dev
