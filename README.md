# Study Planner — лабораторна робота №9

Продовження Study Planner із лабораторної роботи №8. У цій роботі стан застосунку організовано через useReducer та Context API.

## Реалізовано

- керування завданнями через useReducer;
- спільний стан через TaskContext і TaskProvider;
- custom hooks useTaskContext та useLocalStorage;
- збереження завдань і фільтра в localStorage;
- відновлення даних після перезавантаження;
- створення та редагування завдань;
- Toast-повідомлення;
- Undoable Delete із таймером на 5 секунд;
- кнопка скасування видалення;
- візуальний progress bar видалення;
- синхронізація заголовка вкладки;
- скидання до початкових даних;
- SCSS із BEM-структурою за компонентами.

## Запуск

npm install
